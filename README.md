## 상명대학교 2026-1 소프트웨어 공학 3조 팀 프로젝트 프론트

## About Project
본 프로젝트는 상명대학교 2026학년도 1학기 소프트웨어공학 교과목 팀 프로젝트의 프론트 레포지토리입니다.  
사용자의 학습 데이터를 기반으로 단어 학습 및 테스트 기능을 제공하는 웹 서비스의 프론트엔드를 담당합니다.

단어장 조회, 단어 테스트, 관리자용 단어 관리 기능, 회원 기능 등을 중심으로 구성되며,  
REST API 기반으로 백엔드와 통신합니다.

## 기술 스택

- Axios
